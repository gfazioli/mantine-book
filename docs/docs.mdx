## Installation

<InstallScript packages="@gfazioli/mantine-book" />

After installation import package styles at the root of your application:

```tsx
import '@gfazioli/mantine-book/styles.css';
```

You can import styles within a layer `@layer mantine-book` by importing `@gfazioli/mantine-book/styles.layer.css` file.

```tsx
import '@gfazioli/mantine-book/styles.layer.css';
```

## Usage

`Book` renders a realistic page-turn book with corner-driven curl, drag interaction, and click-to-flip. Pages are declared as `<Book.Page>` children — any JSX content goes inside.

<Demo data={demos.usage} />

## Configurator

Tweak the layout, the auto-flip duration, and the shadow intensity. Click the right edge of the spread to flip forward, the left edge to flip back.

<Demo data={demos.configurator} />

## Controlled

Pass `currentPage` and listen to `onPageChange` to drive the book from external state (e.g. a button bar, a deep link, an analytics handler). Each external change animates with the same curl as a click.
